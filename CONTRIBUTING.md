# Contributing to the WOSLand Discord Bot

Thank you for helping improve the WOSLand Discord Bot for Whiteout Survival. Contributions should make the bot safer, more reliable, easier to run, or easier for the community to maintain.

## Before you start

- Check the [README](README.md) and the [project wiki](https://github.com/whiteout-project/bot/wiki).
- Search existing issues and pull requests before opening a new one.
- For larger changes, open an issue or discuss the idea with the maintainers first.
- Do not include bot tokens, API keys, passwords, database files, or other private data in commits.

## Reporting an issue

Please include:

1. A clear description of the problem.
2. Steps to reproduce it.
3. The expected and actual behavior.
4. Relevant log output with secrets removed.
5. Your Python version, deployment method, and any relevant configuration details.

## Making a change

1. Fork the repository and create a focused branch from `main`.
2. Keep each change small and explain why it is needed.
3. Follow the existing Python style and avoid unrelated formatting changes.
4. Update documentation when behavior or setup changes.
5. Add or update tests when practical.
6. Run the available tests and verify the bot starts in a clean environment.
7. Open a pull request with a concise summary, testing notes, and any deployment or migration considerations.

## Pull request checklist

- [ ] The change is focused and documented.
- [ ] Secrets and private data are not included.
- [ ] Tests or manual verification were performed.
- [ ] User-facing behavior and configuration changes are explained.
- [ ] The pull request describes any follow-up work needed.

## Community standards

Be respectful, constructive, and patient. Contributions are reviewed based on their usefulness, safety, maintainability, and fit with the project. Maintainers may request changes before a contribution is merged.
